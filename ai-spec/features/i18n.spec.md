## Supported Languages

| Code | Name | Endonym |
|---|---|---|
| `en` | English | English |
| `fr` | French | Français |
| `vn` | Vietnamese | Tiếng Việt |

Default: `en` (unless `localStorage` has a saved preference).

## Architecture

### Context Layer

```
LanguageContext.js   → createContext()
useLanguage.jsx      → LanguageProvider (wraps App in App.jsx)
useLanguage.js       → useLanguage() hook (consumer)
```

### Provider (`LanguageProvider`)

Wraps the entire app in `App.jsx` (outside `MemoryRouter`).

**State:**
- `language` — current language code (string)
- Initialized from `localStorage.getItem('language')` or defaults to `'en'`

**Effects:**
- On language change: sets `document.documentElement.lang` attribute
- On language change: persists to `localStorage`

**Context value:**
```js
{ language, changeLanguage, t, LANGUAGES }
```

### Translation Function: `t(key)`

Resolves dot-notation keys against `translations.json`:

```js
t('hero.greeting')
// → translations[language].hero.greeting
// → "Hi, I'm Coach E.T" (en)
```

**Fallback:** Returns the raw key string if the path is not found.

Memoized with `useCallback` (dependency: `language`).

## LanguageSwitcher Component

- **Position:** Fixed on screen (positioned via CSS `.language-toggle`)
- **Toggle button:** Shows current language code in uppercase (e.g., `EN`)
- **Dropdown menu:** `.language-menu` with `.active` class when open
- Each option shows `lang.code.toUpperCase()` + `lang.name`
- Active language has `.language-option.active` class
- **Outside click:** Closes menu via document click listener

## What IS Translated (via i18n)

- Navigation labels
- Hero text (greeting, subtitle, description, CTA buttons)
- Section headings (Skills, Strengths)
- Portfolio page title/description and filter labels
- Links page title/description
- Contact page title/description, email label/placeholder, send button, status messages
- Skip-to-main link

---

## What is NOT Translated (Hard-Coded English)

### Intentionally English-only:
- All data files: skills, strengths, projects, resources (technical content)
- Project modal content (problem, solution, tech, lessons)
- Backoffice (all text — see `backoffice.spec.md`)

### Missing translations (could be added):
- Contact form: "Name" label, "Your name" placeholder, "Message" label, message placeholder
- Contact form: all validation error messages
- Card CTAs: "View Details →", "Visit →"
- "Click to see details" in SkillCard / StrengthCard
- Footer social links text ("LinkedIn", "GitHub", "Contact")
- NotFound page: "404", "Page not found.", "Go Home"
